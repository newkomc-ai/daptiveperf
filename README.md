# Adaptive Performance (Fabric 1.21.1, клієнтський мод)

Автоматично підлаштовує дальність промальовки й частинки під FPS.

- Низький FPS -> спочатку зменшує дальність промальовки (до `minRenderDistance`), потім частинки.
- FPS з запасом -> спочатку повертає частинки, потім дальність, але не вище за твоє значення з налаштувань.
- Клавіша **K** вмикає/вимикає мод (можна змінити в Керуванні).
- Налаштування: `config/adaptiveperf.json` (найважливіше: `targetFps`).
- При виході зі світу й закритті гри твої налаштування повертаються як були.

Потрібно: Fabric Loader, Fabric API, Java 21.
